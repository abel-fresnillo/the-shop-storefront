# The Shop Storefront

A React + TypeScript + Vite storefront with a product catalog, shopping cart, and admin panel.

## Overview

The storefront is the customer-facing web application for The Shop. It displays products fetched from the Product API, manages cart state, and submits orders to the Order Service.

## Tech Stack

- **React** + **TypeScript** for the UI
- **Vite** for bundling and local development
- **Vercel** for deployment

## Local Development

```bash
npm install
npm run dev
```
